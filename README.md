# Noticias de El Salvador

Resumen diario automatizado de las cinco noticias más importantes para El Salvador, seleccionadas entre:

- [Diario El Mundo](https://diario.elmundo.sv/)
- [La Prensa Gráfica](https://www.laprensagrafica.com/)
- [El Diario de Hoy](https://www.eldiariodehoy.com/)

Las noticias nacionales tienen prioridad. Una noticia internacional solo entra cuando puede afectar de forma material a El Salvador, por ejemplo por energía, economía, seguridad, clima o fenómenos naturales.

El contenido se actualiza todos los días a las 6:00 a. m., hora de El Salvador.
